1. Что такое наследование?
Наследование — механизм ООП, позволяющий одному классу перенимать свойства и методы другого.

Примеры:
Собака → Животное
Студент → Человек
Машина → Транспорт

2. Основные понятия
Термин	Значение
Базовый класс	родительский класс (тот, у кого наследуют)
Производный класс	класс-потомок (который наследует)
3. Доступ при наследовании
В зависимости от типа наследования меняется уровень доступа к членам базового класса:

Тип наследования	Что происходит
public	доступ сохраняется
protected	становится protected
private	становится private
4. Конструкторы и наследование
При создании объекта производного класса сначала вызывается конструктор базового класса, затем — производного.

Можно переопределять конструкторы (вызывать нужный конструктор родителя).

5. Переопределение методов
Производный класс может изменить поведение метода базового класса.

Для вызова оригинального метода базового класса используется специальный синтаксис (например, Base::method()).

6. Пример из лекции
Создаётся класс Person (базовый) и его наследник (производный класс).

7. Практическое задание (к зачёту)
Создать иерархию:

Employee (базовый класс) — метод work()

Manager, Developer (потомки) — переопределить work()

Добавить уникальные методы: manage(), code()

8. Главные выводы
Наследование помогает:

Переиспользовать код

Расширять функциональность

Строить иерархии классов

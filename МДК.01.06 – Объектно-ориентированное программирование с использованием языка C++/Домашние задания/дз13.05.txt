Конспект: Конструкторы при наследовании и переопределение методов
1. Конструкторы при наследовании
Конструкторы не наследуются автоматически.

У производного класса должен быть свой конструктор.

Производный конструктор обязан вызвать конструктор базового класса.

2. Список инициализации
Базовый класс создаётся до тела конструктора производного.

Единственный корректный способ передать параметры базовому классу.

3. Переопределение методов (override)
Условия:

В базовом классе метод объявлен как virtual.

В производном классе даётся своя реализация.

Ключевые слова:

virtual — разрешает переопределение.

override — гарантирует переопределение (проверяет, что метод действительно переопределён).

4. Примерная структура задачи «Игровые персонажи»
Базовый класс: Character (имя, метод attack()).

Производные: Warrior, Mage.

Требования:

Вызвать конструктор базового класса через список инициализации.

Переопределить attack() с override.

Добавить уникальные методы (slash(), castSpell()).

 Процедурный vs Объектно-ориентированный подход
1. Два подхода к программированию
Процедурный подход
Программа строится как последовательность процедур (функций), работающих с данными. Данные и функции разделены.

Объектно-ориентированный подход (ООП)
Данные и методы их обработки объединяются внутри объектов. Объекты взаимодействуют друг с другом.

2. Основные понятия ООП
Класс — тип данных, описывающий структуру и поведение объектов (поля + методы).

Объект (экземпляр класса) — конкретный представитель класса, имеющий собственное состояние.

Инкапсуляция — скрытие внутреннего состояния объекта, доступ к нему — только через методы (контроль корректности).

3. Пример: банковский счёт (класс BankAccount)
Прямой доступ к полю balance (баланс) запрещён.

Изменение состояния — только через методы (например, deposit(), withdraw()).

Контроль корректности операций (нельзя снять больше, чем есть).

4. Модификаторы доступа в C++
public — доступ отовсюду

private — доступ только внутри класса

protected — доступ внутри класса и наследников

5. Инкапсуляция (кратко)
Механизм сокрытия внутренней реализации.

Обеспечивает контроль доступа к данным.

Позволяет изменять реализацию класса без влияния на внешний код.

6. Основные принципы ООП (упомянутые)
Инкапсуляция

Наследование (возможность создавать новые классы на основе существующих)

Полиморфизм (один интерфейс — разная реализация)

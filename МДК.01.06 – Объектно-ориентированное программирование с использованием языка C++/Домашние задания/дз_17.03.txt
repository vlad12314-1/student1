Жизненный цикл объекта в C++
1. Основные этапы (слайд 02)
Выделение памяти

Инициализация (вызов конструктора)

Использование

Уничтожение (вызов деструктора)

Освобождение памяти

2. Определения (слайд 03)
Конструктор — специальный метод класса, который автоматически вызывается при создании объекта и используется для его инициализации.

Деструктор — специальный метод, который автоматически вызывается при уничтожении объекта (для освобождения ресурсов).

3. Способы создания объектов (слайд 04)
Способ 1: Создание на стеке (автоматическая память).

Способ 2: Создание в куче (динамическая память, оператор new).

4. Инициализация (слайд 05)
Пример использования списка инициализации конструктора (особенно для const полей и объектов без конструктора по умолчанию).

Упоминание перегрузки конструкторов.

5. Перегрузка конструкторов (слайд 06)
В одном классе может быть несколько конструкторов с разными параметрами.

Деструктор — только один (не перегружается).

6. Особый синтаксис (слайд 07)
Делегирующий конструктор (C++11): конструктор может вызывать другой конструктор того же класса.

Правило трех/пяти/нуля: если нужен деструктор, копирующий конструктор или оператор присваивания, скорее всего, нужны и остальные.

Деструктор вызывается автоматически (явно вызывать ~ почти никогда не нужно, кроме редких случаев).

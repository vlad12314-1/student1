«Виртуальные функции»:

1. Виртуальные функции
Объявляются в базовом классе с virtual

Переопределяются в производных классах

Работают через указатели и ссылки

Для контроля переопределения используйте override

2. Чисто виртуальные функции
Не имеют реализации: virtual void func() = 0;

Делают класс абстрактным

3. Абстрактный класс
Нельзя создать объект

Можно использовать как базу

Задаёт интерфейс для производных классов

4. Виртуальный деструктор
Нужен при удалении объекта через указатель на базовый класс

Гарантирует вызов правильного деструктора

5. Когда использовать virtual / =0
Нужен полиморфизм

Поведение зависит от типа объекта

Класс не должен существовать сам по себе (абстрактный)

Задаётся интерфейс

6. Пример: система уведомлений
Абстрактный класс Notification с send() = 0

Классы: EmailNotification, SMSNotification, PushNotification

В каждом своя реализация send()

Итог: изучили виртуальные, чисто виртуальные функции, абстрактные классы и виртуальный деструктор.

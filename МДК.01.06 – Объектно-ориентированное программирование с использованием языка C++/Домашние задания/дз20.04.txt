1. Что такое композиция?
Композиция — способ построения класса, когда один класс содержит объекты других классов.
📌 Пример: класс Car содержит объект Engine.

2. Жизненный цикл (для жёсткой композиции)
Создание: сначала вложенные объекты, потом внешний.

Удаление: сначала внешний объект, потом вложенные.

3. Композиция vs Наследование
Критерий	Композиция (has-a)	Наследование (is-a)
Связь	«имеет»	«является»
Гибкость	высокая	ниже
Изменяемость	легко менять компоненты	сложно менять базу
✅ Композицию выбирают, когда:

нет логической связи «является»

нужна гибкость

возможна замена компонентов

4. Инициализация
Вложенные объекты создаются до тела конструктора → используются списки инициализации.
Без списка инициализации код может не скомпилироваться.

5. Виды композиции
Тип	Жёсткая композиция	Слабая (агрегация)
Создание объекта	внутри класса	передаётся извне
Владение	класс владеет объектом	класс не владеет
Пример	Car создаёт Engine	Car получает готовый Engine
6. Практическое задание (пример)
Система «Компьютер»
Классы: Processor, RAM, GPU
Требования:

композиция (вложенные объекты)

метод start()

конструктор через список инициализации

7. Вывод
Композиция позволяет:
✅ переиспользовать код
✅ избегать сложных иерархий наследования
✅ легко изменять поведение через замену компонентов

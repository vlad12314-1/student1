Инкапсуляция, Getter и Setter
1. Понятие инкапсуляции
Инкапсуляция — ключевой принцип ООП (объектно-ориентированного программирования).

Суть: Данные класса скрыты от прямого доступа извне. Взаимодействие с ними происходит только через специальные методы.

Цели:

Защита данных объекта.

Контроль изменения состояния объекта.

Повышение надежности программы.

2. Скрытие данных (Модификатор private)
Поля класса объявляются с модификатором private.

Это предотвращает некорректное изменение данных напрямую (например, object.age = -5).

3. Getter и Setter (Методы доступа)
Для работы со скрытыми (private) полями создаются публичные методы:

Getter (Геттер): Возвращает значение поля.

Обычное имя: getИмяПоля()

Setter (Сеттер): Устанавливает новое значение поля.

Обычное имя: setИмяПоля(параметр)

4. Пример использования
(Обобщение рисунков 2 и 3)

java
public class Person {
    // 1. Скрываем поле (private)
    private int age;

    // 2. Getter
    public int getAge() {
        return age;
    }

    // 3. Setter
    public void setAge(int age) {
        this.age = age;
    }
}

// Использование:
Person p = new Person();
p.setAge(25);        // Изменяем через setter
System.out.println(p.getAge()); // Читаем через getter
5. Контроль изменения данных (Главный плюс Setter)
Внутри setter можно добавить проверки (валидацию), чтобы защитить логику программы.

Пример (Рисунок 4):

java
public void setAge(int age) {
    if (age > 0 && age < 150) {
        this.age = age;
    } else {
        System.out.println("Ошибка: некорректный возраст");
        // или выбросить исключение
    }
}
6. Указатель this
Что это: Ссылка на текущий объект.

Где нужен: В setter, чтобы различить параметр метода и поле класса (у них одинаковые имена).

this.age — это поле объекта.

age (без this) — это параметр метода.

Итоговая схема (Защита данных):
Поле (private) <-- Setter (контроль) <-- Внешний код --> Getter (чтение) --> Поле 

1. Суть статических членов
Принадлежат классу в целом, а не отдельному объекту.

Существует одна общая копия статического поля для всех объектов.

Изменение в одном объекте → меняется для всех.

2. Статические поля
Общая переменная класса.

Объявление: static int count;

3. Доступ к статическим полям
Через объект: obj.field

Через имя класса: ClassName::field (предпочтительно)

4. Статические методы
Можно вызывать без создания объекта.

Объявление: static void method();

5. Ограничения статических методов
Нет указателя this.

Не могут обращаться к нестатическим полям/методам напрямую.

Работают только со статическими членами.

6. Когда используют
Подсчёт количества объектов.

Хранение общих данных.

Вспомогательные / утилитарные функции.

Реализация классов-утилит (например, математические функции).

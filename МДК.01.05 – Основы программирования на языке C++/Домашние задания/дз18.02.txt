1. Зачем нужны инструменты
Ловить ошибки

Ускорять проверку

Помогать в решении проблем

2. Компиляторные предупреждения
Не текущие ошибки → но почти всегда будущие ошибки

Игнор → undefined behavior (неопределённое поведение)

3. Санитайзеры (ловят ошибки во время выполнения)
AddressSanitizer (ASan)
Ловит:

Выход за границы массива

Use-after-free

Double free

Утечки памяти

Показывает: строку, файл, тип ошибки

UndefinedBehaviorSanitizer (UBSan)
Ловит:

Переполнение int

Деление на 0

Неправильные приведения типов

4. Использование
Можно включать вместе

В Debug — обязательно

5. Почему замедляют?
Вставляют проверки

Следят за памятью
